# Suryansh Chhetry — Personal Portfolio

A responsive personal portfolio built with React, Vite, and CSS.

## Features

- Responsive layout for desktop, tablet, and mobile
- Light/dark theme toggle with a saved browser preference
- Accessible mobile navigation and skip link
- Scroll reveal, floating details, and subtle project visual animations
- Reduced-motion support
- About, toolkit, projects, and contact sections

## Run locally

1. Install [Node.js](https://nodejs.org/).
2. In this folder, run `npm install`.
3. Run `npm run dev` and open the local URL printed by Vite.

Create a production build with `npm run build`. Preview it locally with `npm run preview`.

The page uses Google Fonts from a CDN and falls back to system fonts when offline.

## Customize

- Verify project links and update repository names if they change.
- Review the skill and project descriptions so they accurately reflect your work.
- Add an email address, headshot, or resume link if you want them included.

## Deploy with GitHub Pages

Build the site with `npm run build`, then publish the generated `dist` folder using a static hosting service. For GitHub Pages, configure the repository to deploy the Vite build output.
